Hipótese
h[n−1] = an−1  para algum n ≥ 1
Passo
h[n] = a·h[n−1] + δ[n] = a·an−1 + 0 = an
n ≥ 1 ⇒ δ[n] = 0  ·  usa a hipótese no h[n−1]
∴ h[n] = an para todo n ≥ 0
