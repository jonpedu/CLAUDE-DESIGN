Introdução · 1/2
O sistema: equação de diferenças de 1ª ordem
y[n] = a · y[n−1] + x[n]
y[n]
a saída no instante atual
a · y[n−1]
uma fração da saída anterior volta para o sistema (realimentação)
x[n]
a entrada no instante atual
O sistema tem memória: o coeficiente a decide quanto da saída passada sobrevive a cada passo.
realimentação = memória
Equipe Grupo 1 · Tema 2 — Solução fechada e estabilidade
Introdução · 2/2
Os dois conceitos que o problema usa
Resposta ao impulso h[n]
A saída quando a entrada é x[n] = δ[n] e o sistema parte do repouso, y[−1] = 0.
Num SLIT, h[n] descreve o sistema inteiro: qualquer saída sai dela pela convolução
y[n] = Σk h[k] · x[n−k]
Estabilidade BIBO
“Entrada limitada, saída limitada”: se |x[n]| ≤ B para todo n, então |y[n]| ≤ C para todo n.
Para um SLIT, isso equivale a uma única conta:
estável ⇔ Σn |h[n]| < ∞
em repouso: y[−1] = 0 · entrada δ[n] ⇒ saída = h[n]
conhecendo h[n], qualquer saída sai pela convolução
é essa conta que os passos 3 e 4 fazem

Resolução à mão · Passo 3
Estabilidade pela soma Σ|h[n]|
Por que essa soma?
Com |x[n]| ≤ B, pela convolução:
|y[n]| ≤ Σk |h[k]| · |x[n−k]| ≤ B · Σk |h[k]|
Se a soma é finita, a saída fica presa abaixo de B·Σ|h|, para qualquer entrada limitada.
Aplicando h[n] = aⁿu[n]
Σn=0∞ |aⁿ| = Σn=0∞ |a|ⁿ
Série geométrica de razão |a|. Soma parcial:
SM = (1 − |a|M+1) / (1 − |a|)
|a|M+1 → 0 só se |a| < 1, e então
Σ|h[n]| = 1 / (1 − |a|)
desigualdade triangular + |x| ≤ B
SM: escreve, multiplica por |a| e subtrai
|a| < 1 ⇒ converge · |a| ≥ 1 ⇒ diverge

Erro comum
Esquecer o módulo em Σ|h[n]|
O erro
Ver h[n] de a = −0,8 trocando de sinal e concluir “instável”; ou somar h[n] sem o módulo.
Com a = −1, as somas sem módulo ficam 1, 0, 1, 0, …: parecem limitadas e o sistema parece “estável”.
Como evitar
O critério é Σ|h[n]| = Σ|a|ⁿ: só |a| importa. a = −0,8 dá 5, estável.
a = −1: com módulo, 1, 2, 3, … → ∞, instável. Com x[n] = (−1)ⁿ, limitada, a saída é 1, −2, 3, −4, …

Conclusão
O que fica do tema
1
A recursão leva à forma fechada h[n] = aⁿu[n], provada por indução e conferida em Python.
2
Estável ⇔ Σ|h[n]| < ∞ ⇔ |a| < 1, e nesse caso Σ|h[n]| = 1/(1 − |a|).
3
O sinal de a não decide nada: oscilar não é ser instável.
a = 0,8 e a = −0,8: estáveis, Σ|h[n]| = 5 · a = 1,2: instável.

Equipe Grupo 1 · Tema 2 — Solução fechada e estabilidade
Apêndice · Arguição
Onde exatamente entra o repouso, y[−1] = 0
1. Na primeira conta
h[0] = a·h[−1] + δ[0] = a·0 + 1 = 1
É o ponto de partida da recursão e a base da indução.
2. Nos n negativos
Repouso + causalidade ⇒ h[n] = 0 para n < 0, e é isso que o u[n] registra.
Sem repouso: y[−1] = c
y[n] = c·aⁿ⁺¹ + aⁿ, n ≥ 0
aⁿ: resposta à entrada (estado zero) = h[n]
c·aⁿ⁺¹: resposta à condição inicial (entrada zero)
• h[n] deixaria de ser único (1ª ordem pede 1 condição inicial)
• entrada zero daria saída ≠ 0: não linear
• sem SLIT, convolução e Σ|h| < ∞ não se aplicam
O repouso garante que a saída dependa só da entrada: sem ele não existe uma resposta ao impulso bem definida, e as ferramentas de SLIT não se aplicam.
